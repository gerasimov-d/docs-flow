# Слой `features`

Пользовательские сценарии — то, ради чего пользователь пришёл. Имя слайса это глагол с объектом:
`upload-document`, `search-documents`, `ask-question`.

**Здесь лежит:** сценарий целиком — его UI, состояние и запросы к API.

**Здесь не лежит:** описание самой сущности (её тип, форматирование, карточка) — это `entities`.
Разница простая: сущность отвечает на «что это», фича — на «что с этим делают».

```
features/<slice>/
  api/           запросы к бэкенду через @/shared/api
  model/         состояние, хуки, типы сценария
  ui/            компоненты сценария
  index.ts       public API — наружу отдаётся только то, что перечислено здесь
```

Импортирует: `entities`, `shared`. Другие фичи — нет: общий код поднимается в `entities`
или `shared`.
