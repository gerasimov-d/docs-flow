# Слой `pages`

Страницы: композиция виджетов и фич под конкретный маршрут.

**Здесь лежит:** вёрстка страницы целиком, размещение блоков, работа с параметрами маршрута.

**Здесь не лежит:** бизнес-логика. Страница собирает готовые куски и не реализует сценарии сама.
Если в странице появился запрос к API или сложное состояние — это признак, что сценарий пора
вынести в `features`.

Один слайс — одна страница: `pages/home/`, `pages/document-search/`.

```
pages/<slice>/
  ui/            компоненты страницы
  index.ts       public API — только он виден снаружи
```

Импортирует: `widgets`, `features`, `entities`, `shared`. Другие страницы — нет.
