# Слой `shared`

Переиспользуемый код без привязки к предметной области. Проверка простая: этот код можно
без изменений перенести в другой проект.

**Здесь лежит:** HTTP-клиент (`api/`), UI-примитивы вроде кнопки и поля (`ui/`), утилиты
(`lib/`), константы окружения (`config/`).

**Здесь не лежит:** ничего, что знает слова «документ», «категория», «поиск». Такому место
в `entities` или выше.

Слой поделён не на слайсы, а на сегменты, поэтому сегменты могут опираться друг на друга.
У каждого сегмента свой `index.ts`, и импортируется он целиком: `@/shared/api`, а не
`@/shared/api/http-client`.

Импортирует: только `shared`.
