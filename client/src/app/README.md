# Слой `app`

Инициализация приложения. Всё, что существует в единственном экземпляре и запускается один раз.

**Здесь лежит:** монтирование React (`main.tsx`), глобальные провайдеры (`providers/`), карта
маршрутов (`routes.tsx`), глобальные стили (`styles/`).

**Здесь не лежит:** ни одного продуктового сценария. Если код можно описать словами «пользователь
делает X» — это `features`, а не `app`.

Слой видит все остальные слои. Его самого не импортирует никто.
