# Слой `widgets`

Самостоятельные блоки интерфейса, собранные из нескольких фич или сущностей: шапка, боковая
панель, карточка документа со всеми действиями.

**Здесь лежит:** блок, который страница вставляет одной строкой и который переиспользуется
между страницами.

**Здесь не лежит:** блок, используемый ровно одной страницей и никогда больше — такому место
в самой странице. Слой не обязателен: пока виджетов нет, папка пуста, и это нормально.

```
widgets/<slice>/
  ui/
  model/         состояние блока, если оно есть
  index.ts
```

Импортирует: `features`, `entities`, `shared`. Другие виджеты — нет.
