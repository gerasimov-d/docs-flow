# CLAUDE.md — веб-клиент

Инструкции для агента, работающего с `client/`. Общие правила репозитория — в корневом
`CLAUDE.md`, здесь только то, что касается клиента.

## Что это

SPA на React. Собирается в статику и отдаётся nginx — отдельным контейнером, не бэкендом.
Серверного рендеринга нет и не планируется: вход в приложение за авторизацией, индексировать
нечего.

Стек: Vite, React, TypeScript (strict), React Router, TanStack Query, Tailwind, Vitest.

Интерфейс собран по дизайну «DocsFlow — Web UI» (дизайн-система Organic): тёплая песочная
подложка, терракотовый акцент, шалфейный второй голос, скругления вплоть до таблеток.

## Команды

```bash
npm run check      # типы + линт + формат + тесты, одной командой
npm run dev        # dev-сервер на 5173, /api проксируется на localhost:5023
npm run lint:fix   # починить то, что чинится автоматически
npm run format     # отформатировать
npm run build      # сборка в dist/
```

`npm run check` — то, что должно быть зелёным перед коммитом. Отдельные шаги (`typecheck`,
`lint`, `format:check`, `test`) существуют, чтобы понять, что именно упало.

Бэкенд для `npm run dev` поднимается отдельно: `dotnet run --project src/DocsFlow.Api`.
Без него фронт работает, но запросы к `/api` возвращают ошибку.

Для входа нужен ещё и Keycloak из `docker compose` — он поднимается только в основном
репозитории. Адрес возврата `http://localhost:5173/api/auth/signin-callback` зарегистрирован
в realm, поэтому порт dev-сервера менять нельзя.

## Архитектура: Feature-Sliced Design

Код разложен по слоям. Слой импортирует только те, что ниже него, и только через public API
слайса — его `index.ts`.

| Слой       | Что в нём                                           | Импортирует                                 |
| ---------- | --------------------------------------------------- | ------------------------------------------- |
| `app`      | Инициализация: провайдеры, роутер, глобальные стили | все нижние                                  |
| `pages`    | Страницы под маршруты                               | `widgets`, `features`, `entities`, `shared` |
| `widgets`  | Самостоятельные блоки UI из нескольких фич          | `features`, `entities`, `shared`            |
| `features` | Пользовательские сценарии                           | `entities`, `shared`                        |
| `entities` | Бизнес-сущности                                     | `shared`                                    |
| `shared`   | Код без привязки к предметной области               | `shared`                                    |

Два запрета, которые чаще всего нарушают:

1. **Слайсы одного слоя не видят друг друга.** `features/search-documents` не может
   импортировать `features/upload-document`. Общий код поднимается слоем ниже.
2. **Внутрь чужого слайса ходить нельзя.** Только `@/shared/api`, никогда
   `@/shared/api/http-client`. Нужное наружу — реэкспортируется из `index.ts`.

Это не соглашение на словах: оба правила проверяет ESLint (`boundaries/dependencies`), и
нарушение валит `npm run check`. Подробности каждого слоя — в `README.md` внутри его папки.

## Дизайн-система

Токены живут в `@theme` внутри `app/styles/index.css` — цвета, шрифты, радиусы, тени,
анимация. Имена ролевые: `bg-surface`, `text-ink-muted`, `border-line`, `bg-accent-tint`.
Хексов в разметке нет: правка палитры должна оставаться одной правкой.

Размеры шрифта берутся из дизайна как есть — `text-[13px]`, `text-[28px]`. Это не небрежность:
шкала дизайна (11/12/13/14/15/16/17 и 20/25/28/32/42) не совпадает со шкалой Tailwind, и
собственные имена для неё только добавили бы словарь, который надо помнить.

**Шрифты — Rubik (заголовки) и Onest (текст), и они лежат в репозитории.** Дизайн нарисован
в Caprasimo и Figtree, но ни в одном из них нет кириллицы, а интерфейс русский целиком —
в браузере они свалились бы на системный шрифт. Rubik держит тот же тяжёлый округлый
display-голос, Onest повторяет пропорции Figtree. С CDN они не тянутся: приватность по
умолчанию значит и то, что открытие архива не сообщает стороннему сервису IP пользователя.

Иконки — набор Lucide, вывезенный в `shared/ui/glyphs.tsx` со штрихом 2.75. Пакета
`lucide-react` нет: набор маленький и фиксированный, а зависимость требует согласования.
Новая иконка добавляется в `glyphs.tsx`, и опечатка в `<Icon name>` становится ошибкой сборки.

Примитивы — в `shared/ui`: `Button`, `IconButton`, `Tag`, `Callout`, `Segmented`, `SelectChip`,
`Modal`, `EmptyState`, `Avatar`, `SpaceMark`, `TextInput`, `SectionLabel`. Прежде чем верстать
кнопку руками, стоит посмотреть, нет ли её там.

## Маршруты и space

Идентификатор space стоит в пути каждого экрана с данными: `/s/:spaceId/inbox`,
`/s/:spaceId/documents/:documentId`, `/s/:spaceId/dialogs`. Так ссылка на документ переживает
повторный вход, а арендатор берётся из адреса, который проверяется, — не из состояния клиента.

`SpaceLayout` в `app/` разрешает space из адреса и не пускает дальше, если его нет в списке
доступных. Чужой space и несуществующий дают один и тот же экран «Страница недоступна» —
иначе по разнице ответов можно перебирать чужие архивы. Настоящая проверка живёт в API.

Страницы получают разрешённый space обычным пропом через `SpaceScreen` и про роутер ничего
не знают.

## Как добавить фичу

```
src/features/upload-document/
  api/upload-document.ts     запрос через apiFetch из @/shared/api
  model/use-upload.ts        хук поверх useMutation
  ui/UploadButton.tsx        компонент
  index.ts                   export { UploadButton } from './ui/UploadButton'
```

Дальше фича вставляется в страницу или виджет — одним импортом `@/features/upload-document`.

Сегменты заводятся по мере надобности: если у фичи нет своего состояния, папки `model` быть
не должно. Пустые папки и слайсы «про запас» не создаём.

## Данные с сервера

Только через `apiFetch` из `@/shared/api` и только внутри `useQuery`/`useMutation`.
Прямой `fetch` в компоненте и связка `useEffect` + `setState` для загрузки — не используются:
кеширование, повторы и состояние загрузки уже решены в TanStack Query.

Базовый путь — относительный `/api`. Абсолютных адресов бэкенда в коде нет: в dev запросы
проксирует Vite, в проде — nginx. Поэтому CORS не нужен.

Типы ответов пока описываются руками. Когда у API появятся эндпоинты, их место займёт
генерация из OpenAPI — до тех пор описанный руками тип это временная мера, а не образец.

### Эндпоинтов, которых ещё нет

Половина дизайна опирается на API, которого пока нет: документы, загрузка, поиск, ответы,
удаление контекста и space, приглашение по почте. Эти вызовы сделаны заглушками поверх
`mockRequest` из `@/shared/api`, и каждая помечена `TODO(бэкенд)` с ожидаемым маршрутом.

Правило одно: **заглушка живёт в `api/` своей сущности и повторяет будущую сигнатуру целиком**,
включая обязательный `spaceId`. Компоненты работают с типами из `model/`, поэтому подключение
настоящего эндпоинта — это правка одной функции, а не экрана.

Фикстуры лежат рядом, в `api/fixtures.ts`, и удаляются вместе с заглушками. По ним же собран
маленький движок поиска — без него нельзя увидеть ни пустую выдачу, ни разницу между «точно»
и «по смыслу», ради которых экраны и рисовались.

## Авторизация

Схема — BFF: токенов в браузере нет вообще. API держит их у себя, браузеру отдаёт httpOnly
cookie `docsflow.session`, которую JavaScript не читает. Поэтому на клиенте нет ни библиотеки
OIDC, ни разбора JWT, ни хранения токена — и добавлять их не нужно.

Три обращения к API, и все три особенные:

| Что       | Как                                     | Почему не иначе                                                                      |
| --------- | --------------------------------------- | ------------------------------------------------------------------------------------ |
| Кто вошёл | `GET /api/me` через `useSession()`      | 401 — штатный ответ «не вошёл», он превращается в `null`, а не в ошибку              |
| Вход      | ссылка на `/api/auth/login?returnUrl=…` | дальше цепочка редиректов на Keycloak; `fetch` её не проведёт                        |
| Выход     | POST-форма на `/api/auth/logout`        | ответ — редирект на Keycloak, гасящий SSO-сессию; через `fetch` она осталась бы жива |

Маршруты закрыты `RequireAuth` в `app/`: всё, кроме `/login`, лежит под ним. Гард — это
удобство, а не защита: настоящая проверка в API, который на запрос без сессии отвечает 401.

Antiforgery-токенов пока нет намеренно: единственный POST — выход, а `SameSite=Lax` уже не
пускает cross-site POST. Они появятся вместе с первыми формами, отправляющими данные.

## Тесты

Vitest + Testing Library, файл рядом с кодом: `AnswerView.tsx` → `AnswerView.test.tsx`.
Проверяется поведение через то, что видит пользователь (`getByRole`, `getByText`), а не
внутреннее состояние компонента. Импорты `describe`/`it`/`expect` — явные, глобалов нет.

Тесты покрывают не вёрстку, а обещания, которые нельзя нарушить незаметно:

- чужой space неотличим от несуществующего (`app/space-layout.test.tsx`);
- отказ по формату и размеру происходит до отправки файла (`shared/config/uploads.test.ts`);
- у каждого утверждения ответа есть ссылка на первоисточник, а без фрагментов ответ не
  достраивается (`entities/dialog/ui/AnswerView.test.tsx`).

## Соглашения

- Компоненты — `PascalCase.tsx`, всё остальное — `kebab-case.ts`.
- Импорты внутри `src` — через алиас `@/`, относительные пути только внутри своего слайса.
- Комментарии — русские, идентификаторы — английские (правило репозитория).
- Стили — классы Tailwind в разметке. Отдельные `.css` заводятся, только если задачу нельзя
  решить классами.

## Чего в каркасе намеренно нет

Не додумывать и не добавлять молча — это открытые вопросы, а не забытые:

- **Генерация клиента из OpenAPI.** Типы ответов описаны руками; когда эндпоинтов станет
  больше, их место займёт генерация.
- **Сторонний UI-кит.** Примитивы свои, в `shared/ui`. Подключение библиотеки — отдельное
  решение владельца, и до него новые зависимости не добавляем.
- **Выбор произвольного периода.** Фильтр по дате — пресеты («2026 год», «последний год»):
  календаря-диапазона в дизайне нет, а придумывать его молча нельзя.
- **Мобильная раскладка.** Дизайн нарисован под 1440×900, и адаптива в нём нет.
- **E2E-тесты.** Playwright не подключён.
