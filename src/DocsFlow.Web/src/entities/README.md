# Слой `entities`

Бизнес-сущности предметной области: документ, категория, поисковый фрагмент.

**Здесь лежит:** тип сущности, её представление по умолчанию (карточка, строка списка),
чтение сущности из API, чистые функции над ней.

**Здесь не лежит:** сценарии изменения. «Документ» живёт здесь, «загрузить документ» — в
`features`.

```
entities/<slice>/
  api/
  model/         тип сущности и операции над ней
  ui/            представление по умолчанию
  index.ts
```

Импортирует: `shared`. Другие сущности — нет. Если сущностям нужна связь — её собирает
слой выше.
